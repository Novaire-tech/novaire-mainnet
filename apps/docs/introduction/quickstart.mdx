## Prerequisites

- Node.js ≥ 20.9, npm ≥ 9 (npm workspaces)
- Rust 1.96.0 (pinned in `contracts/rust-toolchain.toml`) with the `wasm32v1-none` target, and `soroban-sdk = "=26.1.0"` (pinned in `contracts/Cargo.toml`)
- Stellar CLI (for contract deployment/interaction)

## Clone and install

```bash
git clone https://github.com/Novaire-tech/novaire-testnet.git
cd novaire-testnet
npm install
cp .env.example .env
```

Fill in `.env` — see [Configuration](/reference/configuration) for what each variable is for. `DATABASE_URL`/`DATABASE_URL_UNPOOLED` are only required if you're running the indexer or Prisma tooling, not for the frontend.

## Run the frontend

```bash
npm run dev
```

This runs `next dev` inside `apps/web` (the only app wired to the root `dev` script).

## Build and test the contracts

```bash
npm run contracts:build   # bash contracts/scripts/build-optimized-wasm.sh
npm run contracts:test    # cargo test --workspace, from contracts/
```

## Deploy to testnet

```bash
npm run deploy            # bash contracts/scripts/deploy-testnet-resilient.sh
```

This is resumable — it persists progress to `deployments/testnet.state.env` and refuses to run against a dirty tracked source tree. It writes the deployed addresses to `deployments/testnet.toml`, `apps/web/src/config/deployments.testnet.json`, and `apps/web/.env.local`. See [Testnet Deployment](/deployment/testnet).

## Verify against live testnet

```bash
npm run verify:testnet    # tsx scripts/verify-testnet.ts
```

Creates real funded testnet wallets and executes real signed transactions against the deployed contracts, cross-checking on-chain reads against an independent TypeScript reimplementation of the pricing formulas. This is a manual step — it is not part of the required CI gate. See [Verification](/deployment/verification).
