## Trait definitions (`shared/types`)

- `StandardizedYield` — `deposit`, `redeem`, `exchange_rate`, `underlying`, `accrued_yield` (implemented by `sy-wrapper`)
- `Market` — `swap_pt_for_sy`, `swap_sy_for_pt`, `swap_sy_for_yt`, `swap_yt_for_sy`, `add_liquidity`, `remove_liquidity`, `implied_apy`, `maturity` (implemented by `amm`)

## No interface exists for

`factory`, `vault`, `marketplace`, `intent_engine`, `maturity_engine`, `rollover` — none of these are deployed contracts in the current architecture.
