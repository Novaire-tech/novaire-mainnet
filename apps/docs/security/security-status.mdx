## Reading this table correctly

An entry marked "Present" means the corresponding test files/functions were found and read in this repository — it does not mean "this component is safe," only "this specific behavior has automated coverage." An entry marked "Not verified" or "Not found" is either explicitly documented as an open gap in `SECURITY.md`, or was not found anywhere in the repository at the time this documentation was prepared. Neither is a claim about mainnet-readiness.
